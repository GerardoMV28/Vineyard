# Vineyard

Proyecto desarrollado en Unity.

## Requisitos
- Unity Editor (versión compatible con el proyecto, ver `ProjectSettings/ProjectVersion.txt`)

## Estructura del proyecto
- **Assets**: Scripts, sprites, sonidos, prefabs y escenas del juego.
- **Packages**: Dependencias del gestor de paquetes de Unity.
- **ProjectSettings**: Configuración del motor, física, inputs y tags.
